# 🎮 Dodge Game

JavaScript와 HTML5 Canvas를 활용하여 구현한 간단한 2D 회피 게임입니다.

플레이어를 좌우로 이동시켜 위에서 떨어지는 적을 피하고, 최대한 오래 생존하는 것을 목표로 합니다.

## 📌 프로젝트 소개

게임 프로그래밍의 기본 구조를 직접 구현하고 이해하기 위해 제작한 미니 프로젝트입니다.

게임의 기본적인 동작 구조인 **키보드 입력 → 게임 상태 업데이트 → 충돌 판정 → 화면 렌더링** 과정을 직접 구현했습니다.

<br>

## 🎯 개발 목적

- 게임 프로그래밍의 기본 구조 이해
- JavaScript 기반 게임 로직 구현
- HTML5 Canvas를 활용한 2D 게임 개발 경험
- 객체의 생성 및 상태 관리 학습
- 충돌 판정 로직 구현
- 게임 난이도와 점수 시스템 구현

<br>

## 🕹️ 주요 기능

- 플레이어 좌우 이동
- 적(Enemy) 랜덤 생성
- 적의 자동 이동
- 플레이어와 적의 충돌 판정
- 생존 시간 기반 점수 증가
- Game Over 처리
- 게임 재시작
- 적 생성 및 이동 속도에 따른 난이도 조절

<br>
